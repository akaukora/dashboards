# TIFF 2026 planner

A schedule planner for the Toronto International Film Festival 2026, live at `https://akaukora.github.io/dashboards/tiff2026/`. It is the HIFF 2026 planner (`../hiff2026/`) with the Toronto program embedded instead; everything in that folder's README applies here.

Pick films, pick screening times, see clashes and tight transfers between venues on a timetable grid, share the plan as a link (`#p=` in the URL) and add screenings to a calendar as `.ics`.

## Files

- `index.html` — the whole planner, with the program from tiff.net embedded as `DATA`. No network requests.
