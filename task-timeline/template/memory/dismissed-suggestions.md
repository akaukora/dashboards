# Dismissed suggestions

Items the assistant proposed as tasks (from email, chat or meetings) that you chose
**not** to track. The weekly update skips anything that matches a line below.

## Formats

- `email:<message-id>` — never re-suggest this one message (most precise)
- `title:<text>` — skip any suggested task whose title contains this text (case-insensitive)
- `subject:<text>` — skip suggestions whose source email subject contains this text

You can also just tell the assistant "dismiss the X suggestion" and it adds the line.
Lines starting with `#` are comments and are ignored.
