Antti's dashboards

Personal data, one page each — films, books, music, festivals and a few games.
github.com/akaukora/dashboards ↗

Every dashboard here is a single HTML file that reads a CSV or JSON next to it and draws everything in the browser — no backend, no tracking. The diaries refresh themselves from the services' data through scheduled GitHub Actions; the rest are built or updated by hand. The three diaries also come as drop-in viewers: open one, drop your own export on it, and you get the same dashboard for your data without uploading anything. The shared look is written up in STYLE.md.
