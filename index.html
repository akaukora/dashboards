I've created tools and dashboards for various interests of mine. These can be downloaded, copied and adapted to your use.

The dashboards are made in HTML with AI coding, or by hand in Tableau. AI coding has revolutionized my data viz workflow. At work, I find myself extracting data from our BI system and doing especially ad hoc, but also repeating analyses using AI coded dashboards. HTML based dashboards are so much more flexible than BI programs are, and the path from idea to prototype to functional dashboard is infinitely faster. For my hobby projects, the same is true. Show more

The dashboards and tools that I have shared here consist of a HTML file that reads a CSV or JSON stored in GitHub, and the data is drawn in the browser. Where you can input your own data (like the music/Spotify dashboard), the data is stored in your own browser.

The diaries refresh themselves from the services' data through scheduled GitHub Actions; the rest are built or updated by hand. The three diaries also come as drop-in viewers: open one, drop your own export (e.g. Spotify) on it, and you get the same dashboard for your data.

There's a folder for each viz in GitHub, with a README on how the data is refreshed. You can take any of them and you (or your AI agent) can rebuild it around your data. Many of the Tableau vizzes were made for #MakeoverMonday, the weekly challenge where the community remakes the same chart from the same data. The shared look is written up in STYLE.md; the chips below filter by theme, by kind, and by where a piece was made.

The HTML dashboards were built with AI assistants — mostly Claude, at times ChatGPT and Perplexity — from Antti Kaukoranta's instructions and design decisions — plain HTML + Chart.js, hosted on GitHub Pages. The Tableau Public vizzes are hand-built. Each folder in the repository has its own README describing the data and how it is refreshed.
